🏷️ 1. React.js Nedir & Virtual DOM Mimarisi

React, arayüz geliştirmeyi modüler kılan bildirime dayalı (declarative) bir JavaScript kütüphanesidir. Gerçek DOM yerine hafızada hafif bir Virtual DOM tutar ve sadece değişen düğümleri (Diffing Algorithm) tarayıcıya yansıtır.

// Vite kullanarak yıldırım hızında proje kurulumu npm create vite@latest proje-adiniz -- --template react cd proje-adiniz npm install npm run dev

🏷️ 2. JSX Derinlemesine & Map İle Liste İşleme

JSX içinde JavaScript ifadeleri {} ile yazılır. Etiketlerin tek bir kapsayıcı ebeveyn (parent) ile sarılması şarttır. Dizileri ekrana basarken her elemana benzersiz bir key verilmelidir.

function KursListesi() { const kurslar = [ { id: 1, ad: "HTML5 & CSS3", tamamlandi: true }, { id: 2, ad: "JavaScript ES6+", tamamlandi: true }, { id: 3, ad: "React.js İleri Düzey", tamamlandi: false } ]; return ( <> <h2>Kurs Listem</h2> <ul> {kurslar.map((kurs) => ( <li key={kurs.id}> {kurs.ad} {kurs.tamamlandi ? "✅" : "⏳"} </li> ))} </ul> </> ); }
📺 Ekran Çıktısı
  • HTML5 & CSS3 ✅
  • JavaScript ES6+ ✅
  • React.js İleri Düzey ⏳

🏷️ 3. Modüler Bileşen Yapısı (Export / Import)

Projedeki her UI elemanı ayrı bir .jsx dosyası olarak tasarlanır. Naming convention gereği bileşen isimleri büyük harfle başlamalıdır.

// components/Button.jsx export function PrimaryButton({ metin }) { return <button className="btn-primary">{metin}</button>; } // App.jsx import { PrimaryButton } from './components/Button'; function App() { return <PrimaryButton metin="Kaydet ve İlerle" />; }

🏷️ 4. Props & Special Prop: children

Props, ebeveyn bileşenden alt bileşene aktarılan salt okunur verilerdir. props.children ise bileşen etiketlerinin arasına yazılan JSX yapılarını yakalamayı sağlar.

// Kart Kapsayıcı Bileşeni function ModalKutusu({ baslik, children }) { return ( <div className="modal-border"> <h3>{baslik}</h3> <div className="modal-body">{children}</div> </div> ); } // Kullanımı <ModalKutusu baslik="Sistem Uyarısı"> <p>Oturum süreniz dolmak üzere, lütfen kaydedin.</p> </ModalKutusu>

🏷️ 5. useState Hook & Kompleks Obje Güncelleme

State doğrudan mutasyona uğratılamaz (örn: kullanici.yas = 25 yapılmaz). Bunun yerine spread operator (...) ile kopyası oluşturularak güncellenir.

import { useState } from 'react'; function ProfilKart() { const [kullanici, setKullanici] = useState({ ad: "Zeynep", rol: "Frontend Developer", takipci: 120 }); const takipEt = () => { setKullanici(prev => ({ ...prev, takipci: prev.takipci + 1 })); }; return ( <div> <h4>{kullanici.ad} ({kullanici.rol})</h4> <p>Takipçi: {kullanici.takipci}</p> <button onClick={takipEt}>Takip Et 🎉</button> </div> ); }

🏷️ 6. Form Yönetimi & useRef Hook

Kontrollü bileşenler state ile yönetilirken, re-render tetiklemeden direkt DOM elemanına erişmek için useRef kullanılır.

import { useRef } from 'react'; function HızlıGiris() { const inputRef = useRef(null); const odaklan = () => { inputRef.current.focus(); // Input alanına imleci koyar inputRef.current.style.borderColor = "#3498db"; }; return ( <div> <input ref={inputRef} type="text" placeholder="Adınız..." /> <button onClick={odaklan}>Girdiye Odaklan</button> </div> ); }

🏷️ 7. useEffect Hook & Cleanup Fonksiyonu

ComponentDidMount, ComponentDidUpdate ve ComponentWillUnmount yaşam döngülerini tek bir hook içinde birleştirir. Clean-up mantığı bellek sızıntısını engeller.

import { useState, useEffect } from 'react'; function Saaat() { const [zaman, setZaman] = useState(new Date().toLocaleTimeString()); useEffect(() => { const interval = setInterval(() => { setZaman(new Date().toLocaleTimeString()); }, 1000); // Cleanup Fonksiyonu (Unmount olduğunda saati durdurur) return () => clearInterval(interval); }, []); // Bağımlılık dizisi boş: Sadece mount anında başlar return <h2>Canlı Saat: {zaman}</h2>; }

🏷️ 8. Özel (Custom) Hooks Üretme

Tekrar eden mantıkları (örn: API çağırma, localStorage senkronizasyonu) kendi yazacağımız `use...` isimli fonksiyonlar haline getirebiliriz.

// hooks/useWindowSize.js import { useState, useEffect } from 'react'; export function useWindowSize() { const [size, setSize] = useState(window.innerWidth); useEffect(() => { const handleResize = () => setSize(window.innerWidth); window.addEventListener('resize', handleResize); return () => window.removeEventListener('resize', handleResize); }, []); return size; }
📺 Ekran Çıktısı

Pencere Genişliği: Dynamically Tracked via Custom Hook

🏷️ 9. Context API (Global State & Prop Drilling Çözümü)

Verileri 10 kat alt bileşene elle aktarmak (Prop Drilling) yerine global bir durum alanında saklayıp her yerden erişmemizi sağlar.

import { createContext, useContext, useState } from 'react'; const TemaContext = createContext(); export function TemaProvider({ children }) { const [tema, setTema] = useState('dark'); return ( <TemaContext.Provider value={{ tema, setTema }}> {children} </TemaContext.Provider> ); } // Alt Bileşende Kullanımı function Header() { const { tema, setTema } = useContext(TemaContext); return <button onClick={() => setTema('light')}>Aktif: {tema}</button>; }
📺 Ekran Çıktısı

Global Tema Durumu: "dark" (Context API Üzerinden Okundu)

🏷️ 10. React Router DOM v6 & Dinamik Parametreler

Tek Sayfa Uygulamalarında (SPA) URL parametrelerini okumak için useParams hook'u kullanılır.

import { useParams, useNavigate } from 'react-router-dom'; function DersDetay() { const { dersId } = useParams(); // URL'deki ID'yi yakalar const navigate = useNavigate(); return ( <div> <h3>Seçilen Ders ID: {dersId}</h3> <button onClick={() => navigate('/')}>Ana Sayfaya Dön</button> </div> ); }

🏷️ 11. Performans Optimizasyonu (useMemo & useCallback)

Gereksiz yeniden hesaplamaları engellemek için useMemo, fonksiyon referanslarını hafızada tutmak için ise useCallback tercih edilir.

import { useMemo } from 'react'; function AğırHesaplama({ sayilar }) { // Sadece sayilar dizisi değiştiğinde tekrar çalışır const toplam = useMemo(() => { console.log("Ağır hesaplama yapılıyor..."); return sayilar.reduce((acc, curr) => acc + curr, 0); }, [sayilar]); return <div>Toplam Sonuç: {toplam}</div>; }
