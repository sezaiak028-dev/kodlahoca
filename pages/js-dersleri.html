🏷️ JavaScript Giriş ve Çıktı Yöntemleri

JavaScript ekrana mesaj bastırmak veya geliştirici konsoluna bilgi yazdırmak için console.log(), alert() ve document.getElementById().innerText komutlarını kullanır.

// Konsola mesaj yazma (F12 > Console) console.log("Merhaba KodlaHoca!"); // Ekrana uyarı penceresi açma alert("Sayfamıza Hoş Geldiniz!"); // HTML elemanının içeriğini değiştirme document.getElementById("mesaj").innerText = "Dinamik İçerik!";
📺 Ekran Çıktısı

Console Çıktısı: "Merhaba KodlaHoca!"

🏷️ Değişkenler (let, const, var)

Verileri hafızada saklamak için kullanılır. Modern JavaScript'te let (değeri değişebilen) ve const (sabit/değişmeyen) tercih edilir.

// Değiştirilebilir değişken (let) let ogrenciSayisi = 30; ogrenciSayisi = 35; // Değer güncellenebilir // Sabit değişken (const) const okulAdi = "KodlaHoca Akademi"; // okulAdi = "Başka Okul"; // HATA! Const değiştirilemez.
📺 Ekran Çıktısı

Öğrenci Sayısı: 35 | Okul: KodlaHoca Akademi

🏷️ Temel Veri Tipleri (Data Types)

JavaScript'te metinler (String), sayılar (Number), mantıksal değerler (Boolean) ve diziler (Array) yaygın kullanılır.

let dersAdi = "JavaScript"; // String let dersSaati = 40; // Number let aktifMi = true; // Boolean let konular = ["HTML", "CSS", "JS"]; // Array (Dizi)
📺 Ekran Çıktısı

typeof "JavaScript" ➔ string
typeof 40 ➔ number
typeof true ➔ boolean

🏷️ Operatörler & Mantıksal Karşılaştırmalar

Aritmetik işlemler ve mantıksal sorgulamalar yapmamızı sağlar (&& VE, || VEYA, === Tam Eşitlik).

let yas = 20; let ehliyetVarMi = true; // Mantıksal VE (&&) Operatörü if (yas >= 18 && ehliyetVarMi === true) { console.log("Araba kullanabilir."); }
📺 Ekran Çıktısı

✅ Şartlar Sağlandı: Araba kullanabilir.

🏷️ Koşul Yapıları (If / Else & Ternary)

Belirli şartlara göre farklı kod bloklarının çalışmasını sağlar.

let not = 75; if (not >= 50) { console.log("Geçtiniz! 🎉"); } else { console.log("Kaldınız. 😞"); } // Kısa İf Kullanımı (Ternary Operator) let durum = (not >= 50) ? "Başarılı" : "Başarısız";
📺 Ekran Çıktısı

Öğrenci Notu: 75 ➔ Durum: Geçtiniz! 🎉

🏷️ Döngüler (For & forEach)

Tekrarlayan işlemleri ve dizi elemanlarını sırayla dönmek için kullanılır.

let diller = ["HTML", "CSS", "JS", "Bootstrap"]; // Standart For Döngüsü for (let i = 0; i < diller.length; i++) { console.log(diller[i]); } // Modern forEach Kullanımı diller.forEach(dil => console.log("Ders: " + dil));
📺 Ekran Çıktısı

1. HTML | 2. CSS | 3. JS | 4. Bootstrap

🏷️ Fonksiyonlar & ES6 Arrow Functions

Tekrar eden kod bloklarını tek bir isim altında toplar. Arrow Function (() => {}) daha pratik kullanım sunar.

// Geleneksel Fonksiyon function topla(a, b) { return a + b; } // Modern Arrow Function (Ok Fonksiyonu) const carp = (a, b) => a * b; console.log(carp(4, 5)); // 20
📺 Ekran Çıktısı

carp(4, 5) Sonucu: 20

🏷️ DOM Manipülasyonu (Sayfayı Dinamikleştirme)

document.querySelector() veya getElementById() ile HTML elemanları yakalanıp metin veya stilleri değiştirilebilir.

const baslik = document.getElementById("demo-baslik"); baslik.style.color = "#e74c3c"; baslik.innerText = "Yazı JS ile Değiştirildi!";
📺 Ekran Çıktısı (Canlı Test)

🏷️ Olay Dinleyicileri (addEventListener)

Kullanıcının tıklama (click), tuşa basma veya form gönderme gibi hareketlerini dinler.

const buton = document.getElementById("btnTıkla"); buton.addEventListener("click", function() { alert("Butona tıklandı!"); });
📺 Ekran Çıktısı (Canlı Test)

🏷️ Modern ES6+ Dizi Metotları (map & filter)

filter() koşula uyanları süzmek, map() ise her elemanı dönüştürmek için kullanılır.

const notlar = [45, 70, 85, 90, 30]; // 50'den büyük notları filtrele const gecenler = notlar.filter(not => not >= 50); // Her nota +5 bonus puan ekle const bonuslu = gecenler.map(not => not + 5); console.log(bonuslu); // [75, 90, 95]
📺 Ekran Çıktısı

Orijinal: [45, 70, 85, 90, 30] ➔ Filtrelenmiş & Bonuslu: [75, 90, 95]

🏷️ Asenkron JS & Fetch API (Veri Çekme)

Sunuculardan canlı veri çekmek ve sayfa yenilenmeden içeriği güncellemek için kullanılır.

async function veriGetir() { try { let yanıt = await fetch('https://api.example.com/data'); let veri = await yanıt.json(); console.log(veri); } catch (hata) { console.error("Hata oluştu:", hata); } }
📺 Ekran Çıktısı

(Asenkron olarak API'den gelen JSON verisi işlenir.)
