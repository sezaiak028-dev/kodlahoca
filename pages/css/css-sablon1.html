🎨 Adım Adım CSS Özellikleri Rehberi

Temel yazı renginden başlayıp adım adım birleşerek karmaşık yapılara dönüşen zincirleme CSS örnekleri.

📍 Adım 1: Yazı Rengi Değiştirme (color)

color özelliği metnin rengini belirler. İlk aşamada doğrudan renk isimleri kullanıyoruz.

🟢 CSS Kodları

/* Kırmızı Yazı */ .yazi-kirmizi { color: red; } /* Mavi Yazı */ .yazi-mavi { color: blue; }

📺 Canlı Görünüm

Bu metin "red" (kırmızı) renktedir.

Bu metin "blue" (mavi) renktedir.

📍 Adım 2: Arka Plan Rengi Verme (background-color)

background-color metnin veya kutunun arkasına zemin rengi ekler.

🟢 CSS Kodları

/* Sarı Arka Planlı Yazı */ .zemin-sari { background-color: yellow; color: black; } /* Mor Arka Planlı Yazı */ .zemin-mor { background-color: purple; color: white; }

📺 Canlı Görünüm

Bu yazının arka planı "yellow" (sarı) rengindedir.

Bu yazının arka planı "purple" (mor) rengindedir.

📍 Adım 3: Yazı Boyutu ve Kalınlığı (font-size & font-weight)

Yazıların büyüklüğünü (px/rem) ve kalınlık derecesini ayarlamamızı sağlar.

🟢 CSS Kodları

/* Küçük ve İnce Metin */ .yazi-kucuk { font-size: 13px; font-weight: normal; } /* Büyük ve Kalın Metin */ .yazi-buyuk { font-size: 22px; font-weight: bold; color: darkgreen; }

📺 Canlı Görünüm

13px boyutunda normal kalınlıkta yazı.

22px boyutunda koyu yeşil ve bold (kalın) yazı.

📍 Adım 4: Kutu Boyutları & Boşluklar (padding & margin)

padding kutunun içindeki elemana olan mesafesi, margin ise kutunun dışındaki elemanlarla olan mesafesidir.

🟢 CSS Kodları

/* İç Boşluklu (Padding) Kutu */ .kutu-padding { width: 250px; height: 60px; padding: 20px; background-color: lightgray; } /* Dış Boşluklu (Margin) Kutu */ .kutu-margin { width: 250px; margin-top: 15px; padding: 10px; background-color: lightblue; }

📺 Canlı Görünüm

Padding (20px İç Boşluk): Yazı kenarlardan uzaktadır.
Margin-Top (15px Dış Boşluk): Üst kutu ile arasına mesafe koydu.

📍 Adım 5: Kenarlıklar & Yuvarlatılmış Köşeler (border & border-radius)

border kenarlık çizer, border-radius ise keskin köşeleri yuvarlar.

🟢 CSS Kodları

/* Düz Kırmızı Kenarlık */ .kutu-border { border: 3px solid red; padding: 10px; } /* Yuvarlatılmış Mavi Kenarlık */ .kutu-yuvarlak { border: 3px solid blue; border-radius: 15px; padding: 10px; } /* Tam Daire Kutu */ .kutu-daire { width: 70px; height: 70px; background-color: orange; border-radius: 50%; }

📺 Canlı Görünüm

Keskin 3px Kırmızı Kenarlık
Köşeleri 15px Yuvarlatılmış Mavi Kenarlık
Daire

📍 Adım 6: Gölgeleme Efektleri (box-shadow)

Kutulara derinlik kazandırmak için yumuşak, keskin veya iç gölge (inset) ekleme örnekleri.

🟢 CSS Kodları

/* 1. Yumuşak Dış Gölge */ .golge-yumusak { box-shadow: 0px 8px 20px rgba(0, 0, 0, 0.2); padding: 10px; background: white; } /* 2. Keskin Retro Gölge */ .golge-keskin { box-shadow: 6px 6px 0px black; border: 2px solid black; padding: 10px; background: #f1c40f; } /* 3. İç Gölge (Inset) */ .golge-ic { box-shadow: inset 0px 0px 10px rgba(0, 0, 0, 0.5); padding: 10px; background: #ecf0f1; }

📺 Canlı Görünüm

Yumuşak Dış Gölge (Soft Shadow)
Keskin Retro Gölge (Hard Shadow)
İç Gölge (Inset Shadow)

📍 Adım 7: Flexbox Hizalama Çeşitleri (space-between, space-around, space-evenly)

display: flex kullanıldığında elemanların yan yana nasıl dağılacağını belirleyen justify-content farkları:

🟢 CSS Kodları

/* 1. space-between (Kenarlara yapışık, aralara eşit boşluk) */ .flex-between { display: flex; justify-content: space-between; } /* 2. space-around (Etrafında eşit boşluk) */ .flex-around { display: flex; justify-content: space-around; } /* 3. space-evenly (Tamamen eşit boşluklar) */ .flex-evenly { display: flex; justify-content: space-evenly; } /* 4. center (Ortalanmış) */ .flex-center { display: flex; justify-content: center; gap: 10px; }

📍 Adım 8: Konumlandırma (position: relative & absolute)

Ana kutuya position: relative verilerek sınır oluşturulur. İçindeki 3 kutu ise position: absolute ile başa (sol üst), ortaya (tam merkez) ve sona (sağ alt) konumlandırılır.

🟢 CSS Kodları

/* Border'lı Ana Kapsayıcı Kutu */ .konum-kapsayici { position: relative; width: 100%; height: 180px; border: 3px dashed #34495e; border-radius: 8px; background-color: #f8fafc; } /* 1. Baş Kutusu (Sol Üst) */ .kutu-baslangic { position: absolute; top: 10px; left: 10px; background-color: red; color: white; padding: 6px 12px; border-radius: 4px; font-weight: bold; } /* 2. Orta Kutu (Tam Merkez) */ .kutu-orta { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); background-color: orange; color: black; padding: 6px 12px; border-radius: 4px; font-weight: bold; } /* 3. Bitiş Kutusu (Sağ Alt) */ .kutu-bitis { position: absolute; bottom: 10px; right: 10px; background-color: green; color: white; padding: 6px 12px; border-radius: 4px; font-weight: bold; }

📺 Canlı Görünüm (Sınırlı Kutu İçi Konumlandırma)

📍 Baştaki Kutu (Sol Üst)
🎯 Ortadaki Kutu (Merkez)
🏁 Bitişteki Kutu (Sağ Alt)

🚀 Adım 9: Kompleks Kart Yapısı (Tüm Kuralların Birleşimi)

Öğrendiğimiz tüm CSS kurallarını (Renk, Arka Plan, Padding, Border-Radius, Gölge, Flexbox ve Position) birleştirerek ürettiğimiz modern kart bileşeni:

🟢 Birleşik CSS Kodları

.kompleks-kart { position: relative; background-color: white; border-top: 4px solid #27ae60; border-radius: 10px; padding: 20px; box-shadow: 0px 10px 25px rgba(0, 0, 0, 0.1); } .kart-header { display: flex; justify-content: space-between; align-items: center; margin-bottom: 10px; } .kart-baslik { color: #2c3e50; font-size: 1.2rem; font-weight: bold; } .kart-etiket { background-color: #eafaf1; color: #27ae60; padding: 4px 10px; border-radius: 15px; font-size: 0.8rem; font-weight: bold; } .kart-buton { background-color: #27ae60; color: white; padding: 8px 16px; border-radius: 5px; text-align: center; font-weight: bold; cursor: pointer; }
