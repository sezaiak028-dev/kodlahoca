🟢 Bu Sitenin HTML & CSS Kodları

Yatay ve dikey açılır menülerin çalışma mantığını gösteren kod bloğu:

<!-- Yatay Navbar --> <li class="nav-item"> <a href="#">Dersler ▾</a> <ul class="dropdown-horizontal"> <li><a href="#">HTML5</a></li> <li><a href="#">CSS3</a></li> </ul> </li> <!-- Dikey Menü (Sidebar) --> <li class="v-item"> <a href="#">Web Tasarım ▸</a> <ul class="dropdown-vertical"> <li><a href="#">Flexbox</a></li> <li><a href="#">CSS Grid</a></li> </ul> </li> /* 2. CSS AÇILIR MENÜ MANTIĞI */ /* Ebeveyn Listeler Relative Olmalı */ .nav-item, .v-item { position: relative; } /* A) YATAY MENÜ (Aşağıya Açılır) */ .dropdown-horizontal { position: absolute; top: 100%; left: 0; /* Tam altına hizalanır */ display: none; } .nav-item:hover .dropdown-horizontal { display: block; } /* B) DİKEY MENÜ (Sağa Doğru Açılır) */ .dropdown-vertical { position: absolute; top: 0; left: 100%; /* Tam sağına hizalanır */ display: none; } .v-item:hover .dropdown-vertical { display: block; }
