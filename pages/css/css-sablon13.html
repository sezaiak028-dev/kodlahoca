🥊 Öğrenci Görevi (Challenge #4 - Final):

Bu final meydan okumasında ekran görünümünü analiz ederek kendi kodlarınızla sayfanın birebir klonunu oluşturun!

  • Main Galeri Düzeni: Main alanında 3'ü üstte 3'ü altta duran 6 adet kartlı resim kutusu (`display: grid; grid-template-columns: repeat(3, 1fr);`) kurun.
  • Hover Opacity Efekti: Görsellerin üzerine gelindiğinde (`:hover`) `opacity` değerinin düşmesini ve yumuşak geçiş vermesini (`transition: opacity 0.4s`) sağlayın.
  • Footer 3'lü Box Yapısı: Footer içinde yan yana duran, belirgin `border` çizgilerine sahip 3 adet eşit genişlikte bilgi kutusu hizalayın.
