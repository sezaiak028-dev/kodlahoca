📱 Şablon 6: Dikey (Vertical) Navbar Menü Tasarımı

Flexbox flex-direction: column mantığı ve konumlandırma özellikleri kullanılarak ekranın sol veya sağ tarafına sabitlenen dikey navigasyon menüleri.

📍 1. Sol Taraf Dikey Menü Tasarımı (Left Vertical Nav)

Dikey menü oluşturmak için kapsayıcıya display: flex ve flex-direction: column verilir. Sol tarafa yaslamak için left: 0 kullanılır.

🟢 HTML & CSS Kodları

<nav class="dikey-menü-sol"> <div class="menu-baslik">MENÜ</div> <ul> <li><a href="#">Ana Sayfa</a></li> <li><a href="#">Hakkımızda</a></li> <li><a href="#">Galeri</a></li> <li><a href="#">İletişim</a></li> </ul> </nav> /* 2. CSS STİLLERİ */ .dikey-menü-sol { position: absolute; top: 0; left: 0; width: 160px; height: 100%; background-color: #1e293b; display: flex; flex-direction: column; /* Dikey Sırala */ } .dikey-menü-sol ul li a { transition: transform 0.3s ease; } /* Hover'da Sağa Doğru Kayma Efekti */ .dikey-menü-sol ul li a:hover { background-color: #38bdf8; color: #0f172a; transform: translateX(5px); }

📺 Canlı Uygulama (Sol Taraf)

Sayfa İçeriği
Sol taraftaki menü left: 0 ile sabitlendi. Fareyle butonların üzerine geldiğinizde sağa doğru hafifçe kayar!

📍 2. Sağ Taraf Dikey Menü Tasarımı (Right Vertical Nav)

Menüyü ekranın sağ tarafında konumlandırmak için right: 0 kullanılır. Hover durumunda ise butonlar içeri doğru (sola) kaydırılabilir.

🟢 HTML & CSS Kodları

<nav class="dikey-menü-sag"> <div class="menu-baslik">NAVİGASYON</div> <ul> <li><a href="#">Ana Sayfa</a></li> <li><a href="#">Hakkımızda</a></li> <li><a href="#">Galeri</a></li> <li><a href="#">İletişim</a></li> </ul> </nav> /* 2. CSS STİLLERİ */ .dikey-menü-sag { position: absolute; top: 0; right: 0; /* Sağa Yasla */ width: 160px; height: 100%; background-color: #0f172a; display: flex; flex-direction: column; } /* Hover'da Sola Doğru Kayma Efekti */ .dikey-menü-sag ul li a:hover { background-color: #e11d48; color: #ffffff; transform: translateX(-5px); }

📺 Canlı Uygulama (Sağ Taraf)

Sayfa İçeriği
Sağ taraftaki menü right: 0 ile sabitlendi. Butonların üzerine geldiğinizde bu kez sola doğru kayar!
