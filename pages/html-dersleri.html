1. Listeler: <ul> ve <ol> Etiketleri

HTML'de verileri sırasız (maddeli) veya sıralı (numaralı) listelemek için sırasıyla <ul> ve <ol> etiketleri kullanılır. Her bir liste maddesi <li> etiketi içerisine yazılır.

<!-- Sırasız Liste (Unordered List) --> <ul> <li>HTML5 Ders Notları</li> <li>CSS3 Tasarım İpuçları</li> <li>JavaScript Kod Blokları</li> </ul> <!-- Sıralı Liste (Ordered List) --> <ol> <li>Birinci Adım: HTML Yapısını Oluştur</li> <li>İkinci Adım: CSS ile Şekillendir</li> <li>Üçüncü Adım: JS ile Etkileşim Ekle</li> </ol>

Sırasız Liste Örneği (Madde İşaretli)

  • HTML5 Ders Notları
  • CSS3 Tasarım İpuçları
  • JavaScript Kod Blokları

Sıralı Liste Örneği (Numaralandırılmış)

  1. Birinci Adım: HTML Yapısını Oluştur
  2. İkinci Adım: CSS ile Şekillendir
  3. Üçüncü Adım: JS ile Etkileşim Ekle

2. Görsel Ekleme: <img> Etiketi

Sayfaya resim dahil etmek için <img> etiketi kullanılır. Kapanış etiketi yoktur (self-closing). Kritik öznitelikler şunlardır:

  • src: Resmin dosya yolu veya web adresidir.
  • alt: Resim yüklenemediğinde veya ekran okuyucularda görüntülenecek alternatif metindir.
  • width / height: Genişlik ve yükseklik değerlerini tanımlar.
<!-- Responsive Görsel Örneği --> <img src="https://via.placeholder.com/600x200/1e3c72/ffffff?text=HTML5+Ders+Gorseli" alt="HTML5 Eğitimi Görseli" class="responsive-img">

3. Çerçeve (<iframe>) ve Bölüm Çizgisi (<hr>)

<iframe> etiketi, web sayfanızın içinde başka bir web sayfasını, haritayı veya videoyu gömmeye yarar. <hr> etiketi ise konular arasına yatay bir ayraç çizgisi çekmek için kullanılır.

<!-- Bölüm Ayracı --> <hr> <!-- iFrame Kullanımı --> <iframe src="https://www.wikipedia.org" title="Wikipedia Dahili Sayfa" class="responsive-iframe"> </iframe>

4. Gelişmiş Öğrenci Kayıt ve Mesaj Formu

Gelişmiş form yapılarında elemanları gruplamak için <fieldset> ve grup başlığı için <legend> kullanılır.

<form action="#" method="post" enctype="multipart/form-data"> <fieldset> <legend>Öğrenci Bilgi Formu</legend> ... Form Elemanları ... </fieldset> </form>
