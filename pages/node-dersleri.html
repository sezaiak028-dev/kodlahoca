🏷️ 1. Node.js Nedir & Event Loop Mimarisi

Node.js, Chrome'un V8 JavaScript motoru üzerine kurulmuş, sunucu tarafında çalışan asenkron ve olay güdümlü (Event-Driven) bir çalışma zamanı ortamıdır (Runtime). Tek iş parçacıklı (Single-Threaded) yapısına rağmen Non-blocking I/O sayesinde eşzamanlı yüksek istekleri karşılar.

// Node.js versiyon kontrolü ve dosya çalıştırma node -v node index.js
📺 Ekran Çıktısı

v20.11.0 ➔ Node.js çalışma ortamı hazır.

🏷️ 2. NPM (Node Package Manager) & Package.json

NPM, projenin bağımlılıklarını (kütüphanelerini) yöneten paket yöneticisidir. Projeyi başlatmak için package.json dosyası oluşturulur.

// Proje paket dosyasını varsayılan ayarlarla başlatma npm init -y // Bağımlılık yükleme (Örn: Express ve SQLite3) npm install express sqlite3 // Geliştirici bağımlılığı yükleme (Örn: Nodemon) npm install -D nodemon
📺 Ekran Çıktısı

package.json dosyası ve node_modules klasörü başarıyla oluşturuldu.

🏷️ 3. Modül Sistemleri (CommonJS vs ES Modules)

Node.js geleneksel olarak require/module.exports (CommonJS) yapısını kullanır. Modern projelerde `package.json` içine "type": "module" eklenerek import/export (ESM) kullanılabilir.

// --- CommonJS Yöntemi --- const math = require('./math'); module.exports = { topla, cikar }; // --- ES Modules Yöntemi --- import express from 'express'; export const topla = (a, b) => a + b;
📺 Ekran Çıktısı

Modüller sorunsuz içe/dışa aktarıldı.

🏷️ 4. Dahili FS (File System) Modülü İşlemleri

Sunucudaki dosyaları okuma, yeni dosya yazma, güncelleme veya silme işlemleri için Node.js'in dahili fs veya fs/promises kütüphanesi kullanılır.

const fs = require('fs/promises'); async function dosyaIslemleri() { try { // Dosyaya veri yazma await fs.writeFile('notlar.txt', 'KodlaHoca Node.js Ders Notları'); // Dosyayı okuma const veri = await fs.readFile('notlar.txt', 'utf-8'); console.log("Okunan Veri:", veri); } catch (err) { console.error("Hata:", err); } } dosyaIslemleri();
📺 Ekran Çıktısı

Okunan Veri: KodlaHoca Node.js Ders Notları

🏷️ 5. Dahili http Modülü ile İlk Sunucu

Herhangi bir harici framework kullanmadan varsayılan http modülüyle temel bir HTTP sunucusu yayına alınabilir.

const http = require('http'); const server = http.createServer((req, res) => { res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' }); res.end('Node.js Dahili HTTP Sunucusundan Merhaba!'); }); server.listen(3000, () => { console.log('Sunucu 3000 portunda dinleniyor...'); });
📺 Ekran Çıktısı

HTTP/1.1 200 OK ➔ Node.js Dahili HTTP Sunucusundan Merhaba!

🏷️ 6. Express.js Mimarisi & Sunucu Kurulumu

Express, Node.js üzerinde web uygulamaları ve API'ler geliştirmek için kullanılan en popüler, esnek ve hızlı web framework'üdür.

const express = require('express'); const app = express(); const PORT = 5000; app.get('/', (req, res) => { res.send('Express.js Sunucusu Yayında! 🚀'); }); app.listen(PORT, () => { console.log(`Sunucu http://localhost:${PORT} üzerinde çalışıyor.`); });
📺 Ekran Çıktısı

Sunucu http://localhost:5000 üzerinde çalışıyor. 🚀

🏷️ 7. Express Routing & HTTP Metotları (CRUD)

İstek türüne göre (GET, POST, PUT, DELETE) sunucunun vereceği yanıtların ve rotaların belirlenmesidir.

app.use(express.json()); // JSON gövdesini okumak için // GET: Veri Çekme app.get('/api/ogrenciler', (req, res) => { ... }); // POST: Yeni Veri Ekleme app.post('/api/ogrenciler', (req, res) => { ... }); // PUT: Güncelleme app.put('/api/ogrenciler/:id', (req, res) => { ... }); // DELETE: Silme app.delete('/api/ogrenciler/:id', (req, res) => { ... });
📺 Ekran Çıktısı

GET /api/ogrenciler ➔ 200 OK | POST /api/ogrenciler ➔ 201 Created

🏷️ 8. Middleware (Ara Yazılım) Mantığı

İstek (Request) ile Yanıt (Response) döngüsü arasında çalışan, kimlik doğrulama, loglama veya veri doğrulama yapan fonksiyonlardır. next() ile bir sonraki adıma geçilir.

// Özel Loglama Middleware'i const logger = (req, res, next) => { console.log(`[${new Date().toISOString()}] ${req.method} ${req.url}`); next(); // Bir sonraki middleware veya rotaya geçiş yap }; app.use(logger); // Tüm uygulamada aktif et
📺 Ekran Çıktısı

[2026-07-30T21:48:00.000Z] GET /api/dersler

🏷️ 9. Standart REST API Mimarisi & Durum Kodları

İstemciye (React, Mobil vb.) standart JSON formatında yanıt dönülmesi ve uygun HTTP durum kodlarının (Status Code) kullanılması ilkesidir.

app.get('/api/ders/:id', (req, res) => { const dersId = req.params.id; if (dersId === "101") { return res.status(200).json({ success: true, ders: "Node.js 101" }); } return res.status(404).json({ success: false, mesaj: "Ders bulunamadı!" }); });
📺 Ekran Çıktısı (JSON Yanıtı)
{
  "success": true,
  "ders": "Node.js 101"
}

🏷️ 10. SQLite Veritabanı İşlemleri (sqlite3)

SQLite, ayrı bir veritabanı sunucusu kurulumu gerektirmeyen, tüm verileri tek bir dosya (`veritabani.db`) içinde saklayan ilişkisel (SQL) bir veritabanıdır.

const sqlite3 = require('sqlite3').verbose(); // 1. Veritabanı Dosyasına Bağlanma / Oluşturma const db = new sqlite3.Database('./veritabani.db', (err) => { if (err) console.error("Bağlantı hatası:", err.message); else console.log("SQLite Veritabanına Başarıyla Bağlanıldı!"); }); // 2. Tablo Oluşturma ve Veri Ekleme db.serialize(() => { db.run(`CREATE TABLE IF NOT EXISTS ogrenciler ( id INTEGER PRIMARY KEY AUTOINCREMENT, ad TEXT NOT NULL, numara INTEGER )`); // Veri Ekleme (INSERT) const stmt = db.prepare("INSERT INTO ogrenciler (ad, numara) VALUES (?, ?)"); stmt.run("Ahmet Yılmaz", 101); stmt.finalize(); // Veri Okuma (SELECT) db.all("SELECT * FROM ogrenciler", [], (err, rows) => { if (err) throw err; console.log("Öğrenci Listesi:", rows); }); });
📺 Ekran Çıktısı

SQLite Veritabanına Başarıyla Bağlanıldı! veritabani.db dosyası oluşturuldu.

🏷️ 11. Çevre Değişkenleri (.env & dotenv)

Veritabanı şifreleri, API anahtarları ve Port bilgilerini kodun içine yazmak yerine .env dosyasında güvenli bir şekilde saklarız.

// .env Dosyası İçeriği PORT=5000 DB_FILE=./veritabani.db JWT_SECRET=super_gizli_anahtar_123 // server.js İçinde Kullanımı require('dotenv').config(); const PORT = process.env.PORT || 3000;
📺 Ekran Çıktısı

process.env.PORT Değeri: 5000 (.env dosyasından okundu)

🏷️ 12. JWT (JSON Web Token) ile Kimlik Doğrulama

Kullanıcı giriş yaptığında (login) sunucu tarafından imzalı bir Token üretilir. İstemci sonraki korumalı isteklere bu token'ı ekler.

const jwt = require('jsonwebtoken'); // Token Üretme (Login anında) const token = jwt.sign( { kullaniciId: "123", rol: "ogrenci" }, process.env.JWT_SECRET, { expiresIn: '1h' } // 1 saat geçerli ); // Token Doğrulama Middleware'i const auth = (req, res, next) => { const token = req.headers['authorization']; if (!token) return res.status(401).send("Erişim Engellendi!"); try { const dogrulanmis = jwt.verify(token, process.env.JWT_SECRET); req.user = dogrulanmis; next(); } catch (err) { res.status(400).send("Geçersiz Token!"); } };
📺 Ekran Çıktısı

Authorization: Bearer eyJhbGciOiJIUzI1Ni... ➔ 200 Authorized
