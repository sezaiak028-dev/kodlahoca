✨ Şablon 4: Gölgeler, Efektler & Pseudo Elements

Kutu gölgeleri (box-shadow), pürüzsüz fare etkileşimleri (:hover & transition) ve HTML'i kirletmeden içerik üreten yalancı elemanlar (:before & :after).

📍 1. Kutu Gölgeleri (box-shadow)

Kutulara derinlik katmak için kullanılır. Sırasıyla: Yatay-Ofset Dikey-Ofset Bulanıklık Renk değerleri verilir.

🟢 CSS Kodları

/* 1. Yumuşak Dış Gölge */ .golge-yumusak { box-shadow: 0px 5px 15px rgba(0, 0, 0, 0.15); } /* 2. Mavi Parlama Gölgeli */ .golge-mavi { box-shadow: 0px 8px 20px rgba(52, 152, 219, 0.4); } /* 3. İç Gölge (Inset) */ .golge-ic { box-shadow: inset 0px 2px 8px rgba(0, 0, 0, 0.3); }

📍 2. Fare Etkileşimi & Geçiş Süresi (:hover & transition)

:hover fareyle üzerine gelince tetiklenir. transition ise bu değişimi pat diye değil, belirlediğimiz süre boyunca (örn: 0.4s) animasyonlu yapar.

🟢 CSS Kodları

.btn-hover { background-color: #3498db; color: white; padding: 10px 20px; border-radius: 6px; /* Pürüzsüz Değişim Süresi */ transition: all 0.4s ease; } /* Fare Üzerine Geldiğinde */ .btn-hover:hover { background-color: #2980b9; transform: translateY(-4px); /* Yukarı kaldır */ box-shadow: 0 6px 15px rgba(41, 128, 185, 0.4); }

📺 Canlı Görünüm (Fareyi Üzerine Getir)

📍 3. Yalancı Elemanlar (:before & :after)

HTML koduna fazladan etiket eklemeden bir elemanın önüne (:before) veya arkasına (:after) sanal içerikler koymamızı sağlar. Zorunlu kural: content: "" yazılmalıdır.

🟢 CSS Kodları

/* 1. :before İle Kutuya Rozet Ekleme */ .kutu { position: relative; } .kutu::before { content: "YENİ"; position: absolute; top: -10px; right: -10px; background-color: #e74c3c; color: white; font-size: 0.75rem; padding: 3px 8px; border-radius: 12px; } /* 2. :after İle Link Altı Çizgi Animasyonu */ .link::after { content: ""; position: absolute; bottom: 0; left: 0; width: 0%; height: 3px; background-color: #27ae60; transition: width 0.3s ease; } .link:hover::after { width: 100%; }
