🖥️ Şablon 7: Örnek Site 1 (Temel Web Sitemiz)

Üç farklı renk ile 3 ana bölüme ayrılmış (Header, Main, Footer), responsive olmayan temel web sitesi örneği.

🌐 Canlı Web Sayfası Önizlemesi

Aşağıda 3 farklı renkli alandan oluşan gerçek bir web sitesi düzeni görülmektedir. Sayfa responsive değildir (Sabit yapılıdır).

📌 Buraya Navbar Gelecek (Navbar Bölümü)

Sitenin logosu ve yönlendirme linkleri bu alanda yer alır.

📝 Buraya Ana İçerik Gelecek (Main Bölümü)

Web sitemizin ana makaleleri, görselleri, duyuruları ve tüm ders içerikleri bu orta alanda sergilenir.

🔻 Buraya Footer Gelecek (Footer Bölümü - Telif Hakları & İletişim)

🟢 Bu Sitenin HTML & CSS Kodları

Yukarıdaki 3 renkli web sitesini oluşturmak için kullanılan kodlar:

<header class="site-header"> <h2>Buraya Navbar Gelecek (Navbar Bölümü)</h2> <p>Sitenin logosu ve yönlendirme linkleri bu alanda yer alır.</p> </header> <main class="site-main"> <h3>Buraya Ana İçerik Gelecek (Main Bölümü)</h3> <p>Web sitemizin ana makaleleri, görselleri ve ders içerikleri bu alanda sergilenir.</p> </main> <footer class="site-footer"> <p>Buraya Footer Gelecek (Footer Bölümü)</p> </footer> /* 2.
