🧭 Şablon 5: Flexbox ile Modern Navbar Menü Tasarımı

Hem HTML iskeleti hem de CSS kodları ile birlikte Flexbox menü yapısı, hover efektleri ve canlı tarayıcı çıktıları.

📍 1. Temel Flexbox Navbar Düzeni

<nav> etiketi kapsayıcı olarak kullanılır. display: flex ve justify-content: space-between ile logo sola, link listesi (<ul>) sağa yaslanır.

🟢 HTML & CSS Kodları

<nav class="navbar"> <div class="logo">KodlaHoca</div> <ul class="nav-links"> <li><a href="#">Ana Sayfa</a></li> <li><a href="#">Hakkımızda</a></li> <li><a href="#">Galeri</a></li> <li><a href="#">İletişim</a></li> </ul> </nav> /* 2. CSS STİLLERİ */ .navbar { display: flex; justify-content: space-between; align-items: center; background-color: #2c3e50; padding: 12px 20px; } .nav-links { display: flex; list-style: none; gap: 15px; }

📍 2. Alt Çizgi Uzama Efektli Navbar

Linklerin altında varsayılan olarak `width: 0%` olan çizgi, fareyle üzerine gelindiğinde (:hover) `width: 100%` olarak pürüzsüzce uzar.

🟢 HTML & CSS Kodları

<nav class="demo-nav-1"> <span class="nav-brand">KodlaHoca</span> <ul> <li><a href="#" class="active">Ana Sayfa</a></li> <li><a href="#">Hakkımızda</a></li> <li><a href="#">Galeri</a></li> <li><a href="#">İletişim</a></li> </ul> </nav> /* 2. CSS STİLLERİ */ .demo-nav-1 ul li a { color: #f8fafc; text-decoration: none; position: relative; padding-bottom: 4px; } /* ::after ile Alt Çizgi */ .demo-nav-1 ul li a::after { content: ""; position: absolute; bottom: 0; left: 0; width: 0%; height: 2px; background-color: #38bdf8; transition: width 0.3s ease; } .demo-nav-1 ul li a:hover::after, .demo-nav-1 ul li a.active::after { width: 100%; }

📍 3. Buton (Pill) Stilli & Kalkma Efektli Navbar

<a> etiketlerine padding ve border-radius: 20px verilerek kapsül buton tarzı elde edilir. Hover anında transform: translateY(-2px) ile hafifçe yukarı kalkar.

🟢 HTML & CSS Kodları

<nav class="demo-nav-2"> <span class="nav-brand">⚡ PORTAL</span> <ul> <li><a href="#" class="active">Ana Sayfa</a></li> <li><a href="#">Hakkımızda</a></li> <li><a href="#">Galeri</a></li> <li><a href="#">İletişim</a></li> </ul> </nav> /* 2. CSS STİLLERİ */ .demo-nav-2 ul li a { color: #475569; padding: 6px 14px; border-radius: 20px; transition: all 0.3s ease; } /* Hover Efekti */ .demo-nav-2 ul li a:hover { background-color: #3b82f6; color: #ffffff; transform: translateY(-2px); box-shadow: 0 4px 10px rgba(59, 130, 246, 0.3); } .demo-nav-2 ul li a.active { background-color: #0f172a; color: #ffffff; }
