✨ Şablon 3: Spacing, Text Decoration, Align & Düzen

Margin/Padding detayları, özel metin çizgileri, hizalama, opaklık, görsel sığdırma (object-fit), katman sırası (z-index) ve taşma (overflow) özellikleri.

📍 1. CSS Spacing (Boşluklar: Margin & Padding)

padding kutunun iç boşluğudur, margin ise dış boşluğudur. Saat yönü sırasıyla yazılır: Üst - Sağ - Alt - Sol (TRBL).

🟢 CSS Kodları

/* İç Boşluk (Padding) */ .ic-bosluk { padding: 15px 25px; /* Üst-Alt: 15px, Sağ-Sol: 25px */ background-color: #3498db; color: white; } /* Dış Boşluk (Margin) */ .dis-bosluk { margin-top: 20px; margin-bottom: 10px; background-color: #e74c3c; color: white; padding: 10px; }

📺 Canlı Görünüm

Padding (İç Boşluk): Yazı kenarlardan uzakta durur.
Margin (Dış Boşluk): Üst kutuyla arasına 15px mesafe koydu.

📍 2. Text Decoration & Style (Metin Çizgi Stilleri)

Metinlerin altına, üstüne veya ortasına dalgalı (wavy), kesikli (dotted) ve çift (double) çizgiler çizebiliriz.

🟢 CSS Kodları

/* 1. Dalgalı Kırmızı Alt Çizgi */ .cizgi-dalgali { text-decoration-line: underline; text-decoration-style: wavy; text-decoration-color: red; } /* 2. Kesikli Yeşil Üstü Çizili */ .cizgi-kesikli { text-decoration-line: line-through; text-decoration-style: dotted; text-decoration-color: green; } /* 3. Çift Mor Üst Çizgi */ .cizgi-cift { text-decoration-line: overline; text-decoration-style: double; text-decoration-color: purple; }

📺 Canlı Görünüm

Dalgalı Kırmızı Alt Çizgi (wavy underline)

Kesikli Yeşil Üstü Çizili (dotted line-through)

Çift Mor Üst Çizgi (double overline)

📍 3. CSS Hizalama (text-align & margin: auto)

Metinleri text-align ile, blok kutuları ise margin: 0 auto ile yatayda kolayca ortalayabiliriz.

🟢 CSS Kodları

/* Metin Hizalama */ .yazi-sol { text-align: left; } .yazi-orta { text-align: center; } .yazi-sag { text-align: right; } /* Kutuyu Sayfada Ortala */ .kutu-ortala { width: 60%; margin: 0 auto; /* Blok kutuyu ortalar */ background-color: #2c3e50; color: white; }

📺 Canlı Görünüm

Sola Hizalı Metin (left)
Ortalanmış Metin (center)
Sağa Hizalı Metin (right)
Blok Kutu (margin: 0 auto ile ortalandı)

📍 4. CSS Opacity (Saydamlık / Şeffaflık)

opacity değeri 0.0 (görünmez) ile 1.0 (tam görünür) arasında değer alır.

🟢 CSS Kodları

.opaklik-100 { opacity: 1.0; } /* %100 Net */ .opaklik-75 { opacity: 0.75; }/* %75 Net */ .opaklik-50 { opacity: 0.50; }/* %50 Yarı Saydam */ .opaklik-25 { opacity: 0.25; }/* %25 Çok Saydam */

📺 Canlı Görünüm

1.0 (%100)
0.75 (%75)
0.50 (%50)
0.25 (%25)

📍 5. CSS Object-Fit (Görsel Sığdırma)

Sabit boyutlu bir resim kutusunun içine görselin oranları bozulmadan yayılmasını sağlar.

🟢 CSS Kodları

/* Resmin oranını bozmadan kutuyu doldurur (Kırpar) */ .resim-cover { width: 100px; height: 100px; object-fit: cover; } /* Resmin tamamını kutunun içine sığdırır */ .resim-contain { width: 100px; height: 100px; object-fit: contain; }

📺 Canlı Görünüm

object-fit: cover
object-fit: contain

📍 6. CSS Z-Index (Ön-Arka Katman Derinliği)

Üst üste binen kutularda hangisinin önde duracağını belirler. z-index değeri yüksek olan üstte görünür (Çalışması için position şarttır).

🟢 CSS Kodları

.kutu-kirmizi { position: absolute; top: 0; left: 0; z-index: 1; /* En Altta */ } .kutu-yesil { position: absolute; top: 20px; left: 30px; z-index: 3; /* En Üstte */ } .kutu-mavi { position: absolute; top: 40px; left: 60px; z-index: 2; /* Ortada */ }

📺 Canlı Görünüm (Üst Üste Binen Katmanlar)

z-index: 1
z-index: 3 (Üstte)
z-index: 2

📍 7. CSS Overflow (Taşma Yönetimi)

Kutunun boyutu içindeki metne yetmediğinde hidden ile gizlenebilir, scroll veya auto ile kaydırma çubuğu eklenebilir.

🟢 CSS Kodları

/* Taşan Kısımı Gizle */ .overflow-gizli { width: 150px; height: 60px; overflow: hidden; } /* Kaydırma Çubuğu Ekle */ .overflow-kaydir { width: 150px; height: 60px; overflow: auto; }

📺 Canlı Görünüm

overflow: hidden
Bu metin kutudan taşacağı için kalan kısmı gizlenir.
overflow: auto
Bu metin kutudan taşacağı için otomatik kaydırma çubuğu çıkar.
