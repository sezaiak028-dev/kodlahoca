🎯 Şablon 2: CSS Seçiciler (Selectors) Rehberi

CSS kurallarını HTML elemanlarına nasıl bağlayacağımızı belirleyen temel seçici türleri ve kullanım farkları.

📍 1. Evrensel Seçici (Universal Selector: *)

Yıldız (*) sembolü ile kullanılır. Sayfadaki istisnasız tüm HTML elemanlarını seçer. Genellikle tarayıcı varsayılan boşluklarını sıfırlamak için tercih edilir.

🟢 CSS Kodları

/* Tüm elemanların varsayılan boşluklarını sıfırla */ * { margin: 0; padding: 0; box-sizing: border-border-box; font-family: Arial, sans-serif; }

📺 Açıklama & Kullanım Amacı

💡 İpucu:

Evrensel seçici, projelerin en başında CSS sıfırlama (reset) yapmak için kullanılır. Sayfadaki her etikete aynı temel kuralı uygular.

📍 2. Etiket Seçici (Element / Tag Selector)

Doğrudan HTML etiket adıyla (h1, p, button vb.) yazılır. O etiket türündeki bütün elemanları etkiler.

🟢 CSS Kodları

/* Tüm h3 başlıklarını mavi yap */ h3 { color: darkblue; border-bottom: 2px solid darkblue; } /* Tüm paragrafları italik yap */ p { font-style: italic; color: darkslategray; }

📺 Canlı Görünüm

Bu bir h3 başlığıdır

Bu bir paragraftır. Sayfadaki tüm p etiketleri italik görünür.

📍 3. Sınıf Seçici (.class Selector)

Başına nokta (.) koyarak yazılır. HTML'de class="..." özniteliğine sahip birden fazla elemana aynı stili vermek için kullanılır (Tekrar kullanılabilirlik).

🟢 CSS Kodları

/* .vurgulu-kutusu sınıfı */ .vurgulu-kutu { background-color: #fff3cd; border: 2px solid #ffeeba; color: #856404; padding: 10px; border-radius: 6px; font-weight: bold; }

📺 Canlı Görünüm (Aynı Sınıf Farklı Yerlerde)

1. Eleman (.vurgulu-kutu sınıfı eklendi)

2. Eleman (Farklı bir paragraf ama aynı sınıfı kullanıyor)

📍 4. ID Seçici (#id Selector)

Başına kare/diyez (#) konularak yazılır. Sayfada sadece 1 tane benzersiz elemanı hedeflemek için kullanılır (Özel butonlar, ana başlıklar vb.).

🟢 CSS Kodları

/* #ana-baslik kimliği (Benzersizdir) */ #ozel-kayit-butonu { background-color: #27ae60; color: white; padding: 12px 24px; border: none; border-radius: 25px; font-size: 1rem; font-weight: bold; cursor: pointer; box-shadow: 0 4px 10px rgba(39, 174, 96, 0.4); }

📺 Canlı Görünüm

🚀 5. Karma Kullanım & Seçici Önceliği (Specificity)

CSS'te bir elemana aynı anda Etiket, Class ve ID stili verilirse en güçlü olan ID'dir (ID > Class > Etiket).

🟢 CSS Önem Sırası Kodları

/* 1. Önceliği En Düşük (Etiket) */ p { color: black; } /* 2. Orta Öncelikli (Class - Etiketi ezer) */ .mavi-metin { color: blue; } /* 3. En Yüksek Öncelikli (ID - Hepsini ezer) */ #kirmizi-kazanan { color: red; font-weight: bold; }

📺 Canlı Öncelik Testi

1. Sadece <p> etiketi (Siyah)

2. <p class="mavi-metin"> (Siyahı ezdi, Mavi oldu)

3. <p class="mavi-metin" id="kirmizi-kazanan"> (Class'ı da ezdi, Kırmızı kazandı!)
