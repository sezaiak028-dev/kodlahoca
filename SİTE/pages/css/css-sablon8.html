🖥️ Şablon 8: Örnek Site 2 (Çift Dikey Menülü Web Sayfası)

Hem Sol Menü hem Sağ Menü içeren, Flexbox mimarisiyle 3 farklı dikey kolona ayrılmış responsive olmayan temel web sitesi örneği.

🌐 Canlı Web Sayfası Önizlemesi

Aşağıdaki simülasyonda sol dikey menü, orta içerik alanı ve sağ dikey menü `display: flex` yapısıyla yan yana konumlandırılmıştır.

📌 Buraya Üst Header / Navbar Gelecek

👈 Sol Menü
  • Ana Sayfa
  • Hakkımızda
  • Dersler
  • İletişim

📝 Buraya Ana İçerik Gelecek (Main)

Sitenin makaleleri, duyuruları ve ders içerikleri bu orta alanda yer alır. Sol ve sağ sütunlar `display: flex` sayesinde yanına dizilmiştir.

👉 Sağ Menü
  • Son Duyurular
  • Faydalı Linkler
  • Kategoriler
  • Sponsorlar
🔻 Buraya Footer Gelecek (Footer Bölümü)

🟢 Bu Sitenin HTML & CSS Kodları

Yukarıdaki sol ve sağ dikey menülü web sitesini oluşturmak için kullanılan kodlar:

<header class="site-header"> <h2>Buraya Üst Header / Navbar Gelecek</h2> </header> <div class="site-body-container"> <!-- SOL DİKEY MENÜ --> <aside class="sidebar-left"> <h4>Sol Menü</h4> <ul> <li><a href="#">Ana Sayfa</a></li> <li><a href="#">Hakkımızda</a></li> </ul> </aside> <!-- ORTA ANA İÇERİK --> <main class="site-main"> <h3>Buraya Ana İçerik Gelecek (Main)</h3> </main> <!-- SAĞ DİKEY MENÜ --> <aside class="sidebar-right"> <h4>Sağ Menü</h4> <ul> <li><a href="#">Duyurular</a></li> <li><a href="#">Linkler</a></li> </ul> </aside> </div> <footer class="site-footer"> <p>Buraya Footer Gelecek</p> </footer> /* 2. CSS STİLLERİ */ .site-header { background-color: #2c3e50; color: white; padding: 20px; text-align: center; } /* ORTA GOVDENİN YAN YANA FLEX DÜZENİ */ .site-body-container { display: flex; /* Sol Menü, Main ve Sağ Menüyü yan yana dizer */ min-height: 300px; } .sidebar-left { width: 180px; background-color: #34495e; color: white; padding: 15px; } .site-main { flex: 1; background-color: #16a085; color: white; padding: 30px; text-align: center; } .sidebar-right { width: 180px; background-color: #8e44ad; color: white; padding: 15px; } .site-footer { background-color: #e67e22; color: white; padding: 15px; text-align: center; }
