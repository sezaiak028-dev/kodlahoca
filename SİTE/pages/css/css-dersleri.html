🎯 CSS Seçiciler (Selectors)

HTML elemanlarını hedef alarak stil uygulamamızı sağlar. Eleman adı, Sınıf (Class - .) ve Kimlik (ID - #) seçicileri en sık kullanılanlardır.

/* Eleman Seçici */ p { color: #2c3e50; } /* Class (Sınıf) Seçici */ .vurgu-metni { color: #e74c3c; font-weight: bold; } /* ID (Kimlik) Seçici */ #ozel-baslik { background-color: #f1c40f; padding: 5px; }

🎨 Renkler & Arka Plan (Background)

Metin rengi için color, arka plan rengi için background-color kullanılır.

.renkli-kutu { color: #ffffff; background-color: #3498db; padding: 10px; }

📦 Kutu Modeli (Margin & Padding)

padding elemanın içindeki içeriğe boşluk verir, margin ise dış boşluk bırakır.

.kutu { background-color: #e8f4fc; border: 1px solid #3498db; padding: 15px; margin: 10px 0; }
📺 Ekran Çıktısı

🖼️ Kenarlık (Border) Özellikleri

Elemanların etrafına çizgi ekler. Çizgi kalınlığı, türü (solid, dashed, dotted) ve rengi belirlenebilir.

.duz-kenar { border: 2px solid #2ecc71; } .kesikli-kenar { border: 2px dashed #e74c3c; }

📱 Responsive Tasarım Nedir?

Responsive (Duyarlı/Esneme Uyumlu) tasarım; web sitelerinin masaüstü bilgisayarlar, tabletler ve akıllı telefonlar gibi farklı ekran boyutlarına ve çözünürlüklerine otomatik olarak uyum sağlamasıdır.

CSS'te responsive tasarımın temelini Viewport Meta Etiketi, esnek ızgara sistemleri (Flexbox / Grid) ve @media sorguları oluşturur.

<meta name="viewport" content="width=device-width, initial-scale=1.0"> <style> /* Sabit Genişlik (Responsive Değil - Ekran Daralınca Taşar) */ .kutu-sabit { width: 600px; } /* Esnek Genişlik (Responsive Uyumlu - Ekran Daraldıkça Küçülür) */ .kutu-esnek { width: 100%; box-sizing: border-box; } </style>

💡 Canlı Davranış Farkı (Pencereyi Daraltarak / F12 İncele ile Test Edin):

❌ width: 600px; (Sabit Genişlik! Ekran daralsa da 600px kalır, mavi çerçevenin sağından dışarı fırlar)
✅ width: 100%; (Esnek Genişlik! Mavi çerçeve ve ekranla birlikte milim milim daralır)

⚙️ @media Sorgusu Sözdizimi

@media kuralı, CSS kodlarının yalnızca belirlediğimiz belirli ekran koşulları (örneğin ekran genişliği 768px veya daha altındaysa) sağlandığında devreye girmesini sağlar.

En yaygın kullanım şekli, cihaz türü olarak screen (ekran) ve ekran şartı olarak max-width (maksimum genişlik) belirlemektir.

/* Temel @media Yapısı */ @media screen and (max-width: 768px) { /* Ekran genişliği 768px veya daha KÜÇÜK olduğunda çalışacak CSS kodları */ .media-demo-box { background-color: #e67e22 !important; /* Turuncu renge dön */ color: #ffffff; font-size: 0.9rem; } }

📐 Breakpoints (Ekran Kesme Noktaları)

Breakpoint (Kesme Noktası), web tasarımının farklı cihaz ekranlarına uyum sağlamak için biçim değiştirdiği piksel sınırıdır.

Sektörde (Bootstrap ve Tailwind gibi kütüphanelerde de) kabul gören standart ekran genişlik sınırları şunlardır:

/* 1. Ekstra Küçük Cihazlar (Mobil Telefonlar: < 576px) */ @media screen and (max-width: 575px) { ... } /* 2. Tablet Cihazlar (576px - 768px) */ @media screen and (min-width: 576px) and (max-width: 768px) { ... } /* 3. Masaüstü Ekranlar (992px ve üzeri) */ @media screen and (min-width: 992px) { ... }

💡 Canlı Breakpoint Testi (Ekran Genişliğini Değiştirin):

📐 Esnek Düzen (Flex/Grid & @media)

Masaüstü ekranlarda yan yana dikey sütunlar halinde sıralanan kartlar veya menüler, mobil ekranlarda yer darlığı nedeniyle alt alta dizilmelidir.

Bu dönüşümü sağlamak için Flexbox kullanıyorsak flex-direction: column, CSS Grid kullanıyorsak grid-template-columns: 1fr kuralını @media bloğu içinde tanımlarız.

/* Masaüstünde 3 Kolonlu Grid Yapısı */ .kart-grubu { display: grid; grid-template-columns: repeat(3, 1fr); gap: 15px; } /* Mobilde (<= 768px) Tek Kolona Düşürme */ @media screen and (max-width: 768px) { .kart-grubu { grid-template-columns: 1fr; /* Tüm kartlar alt alta dizilir */ } }

🖼️ Responsive Görseller & Tipografi

Ekran daraldığında görsellerin taşmasını engellemek ve metin boyutlarının mobil cihazlarda okunabilir kalmasını sağlamak responsive tasarımın temel kuralıdır.

/* 1. Responsive Görsel (Taşmayı Önler, Orantılı Küçülür) */ img.responsive-img { max-width: 100%; height: auto; display: block; } /* 2. Responsive Tipografi (@media ile Metin Boyutu) */ h2.responsive-text { font-size: 2rem; /* Masaüstü */ } @media screen and (max-width: 768px) { h2.responsive-text { font-size: 1.3rem; /* Mobilde Küçülen Başlık */ } }

📱 Mobile-First vs Desktop-First

Responsive tasarım yaparken CSS kodlarını yazmanın iki farklı yaklaşımı vardır: Desktop-First (Masaüstünden Mobile) ve Mobile-First (Mobilden Masaüstüne).

Günümüzde mobil internet kullanımı baskın olduğu için modern projelerde ve kütüphanelerde (Bootstrap, Tailwind gibi) ağırlıklı olarak Mobile-First (min-width) yaklaşımı tercih edilir.

/* 1. DESKTOP-FIRST YAKLAŞIMI (Masaüstünden Mobile) */ /* Varsayılan: Masaüstü stilleri yazılır */ .box { width: 33.33%; float: left; } /* Ekran küçüldükçe daraltılır */ @media screen and (max-width: 768px) { .box { width: 100%; float: none; } } /* 2. MOBILE-FIRST YAKLAŞIMI (Mobilden Masaüstüne - ÖNERİLEN) */ /* Varsayılan: Mobil stilleri yazılır (Yalın ve hızlı) */ .box { width: 100%; } /* Ekran genişledikçe ek özellikler yüklenir */ @media screen and (min-width: 769px) { .box { width: 33.33%; float: left; } }
